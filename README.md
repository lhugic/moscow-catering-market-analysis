# Исследование рынка общественного питания Москвы

## О проекте
Комплексный EDA рынка общественного питания Москвы по данным более 8000 заведений.

**Цель:** понять структуру рынка (форматы, география, вместимость, чеки) для подготовки к запуску нового заведения.

## Данные
Два датасета, объединённых по id:
- `rest_info.csv` — тип, адрес, округ, рейтинг, сетевой признак, количество мест
- `rest_price.csv` — средний чек

## Стек
- Python, Pandas, Matplotlib, Seaborn, Phik
- Merge, очистка пропусков и дубликатов, создание новых признаков, корреляции

## Главные выводы

**Структура рынка**
- Лидеры по числу точек — кафе, рестораны и кофейни.
- Более 60% рынка — одиночные (несетевые) проекты.

**Сети**
- Сетевой формат сильнее в простых концептах: 61% булочных и 52% пиццерий — сети.
- Сети либо захватывают центр, либо покрывают спальные районы под доставку.

**География**
- ЦАО лидирует по концентрации и цене. Медианный чек — 1000 руб.
- На окраинах (ЮВАО, СВАО) средний чек падает в 2 раза — до 450–500 руб.

**Вместимость**
- Рестораны и бары — в среднем 80–86 мест.
- Фастфуд, пиццерии и кофейни — около 50 мест.

**Рейтинги**
- Средние оценки высокие (от 4 баллов) из-за конкуренции.
- Дорогие заведения стабильно держат качество, в бюджетном сегменте оценки более разбросаны.

## Рекомендации
1. Для крупной сети лучше выбирать простой продукт (кофейня, пекарня, пиццерия). Для одиночного проекта — кафе или ресторан.
2. Премиум с высоким чеком — в ЦАО или ЗАО. В спальных районах — бюджетный формат + доставка.
3. Для пекарни или стрит-фуда оптимальна вместимость 40–50 мест.
